# How to become a contributor to Root OS?

Thank you for your interest in helping the project! We welcome any contributions — from fixing typos to adding new features.

---

## Getting Started

1. Find something you'd like to change *(it could even be an issue from the Issue tracker)*
2. Fork this repository and create a branch
3. Make your changes
4. Submit a Pull Request

---

## Guidelines

- Please add comments to any code you modify
- Test your changes before submitting
- Commit messages should be written in English

---

## How to submit a Pull Request

1. Fork this repository
2. Create a branch: `git checkout -b feature/your-feature-name`
3. Make your changes and commit them: `git commit -m "Brief description of changes"`
4. Push to your fork: `git push origin feature/your-feature-name`
5. Open a Pull Request

---

## What does the maintainer (me) do?

- I review the changes and decide whether to accept them or request further improvements

---

### Questions?

Feel free to open an Issue — I'll get back to you!
